# 前端设计提示词

## 1. 深色模式模型选择列表（原生 CSS）

```text
你现在是一个顶级的资深前端 UI 设计师。请忽略工程化思维，我要一个直接能在浏览器打开的单文件 HTML。

请你全力发挥你的审美，使用纯原生 CSS 和现代设计语言，帮我设计一个【深色模式的模型选择列表】。
强制要求（必须全部实现）：

不要使用任何外部 UI 库，用原生 CSS 写。

整体背景用深灰 #1c1c1e，卡片用稍亮的深灰，加上非常柔和的微阴影和 8px 圆角。

列表项要使用 Flex 布局，实现左侧图标、中间标题与多色 Tag、右侧价格的完美对齐。

Tag 必须实现四种精美样式：橙色半透明底（new）、红色半透明底（限时免费）、蓝色实心底（错峰使用）、绿色半透明底（订阅优先）。

给列表加上 Hover 时的浅色背景过渡动画，底部加上带有输入框和蓝色主按钮的固定栏。

直接输出完整的 HTML 代码，不要偷懒省略 CSS，我要直接看到绝美的效果！
```

## 2. 页面结构约束

```text
页面结构必须是：顶部大标题（如'Max 模式'）；中间是列表区，每一行是一个 Flex 容器（左图标、中名称+Tag、右价格）；最底部固定一个操作栏（输入框 + 蓝色按钮）。行与行之间保持 12px 的间距。
```

## 3. Tailwind CDN 变体

```text
请使用 Tailwind CSS 的 CDN（https://cdn.tailwindcss.com）来编写样式。不要写任何自定义的 <style> 标签，全部使用 Tailwind 的原子类（如 bg-gray-900、rounded-lg、flex、items-center、p-4 等）来实现。确保页面具有现代、高端的深色 UI 质感。
```
